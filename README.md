# 📜 Beyond The Pages

**Beyond The Pages** é uma plataforma premium de gerenciamento de biblioteca pessoal, projetada para leitores que buscam uma experiência imersiva e organizada. O sistema permite catalogar leituras, acompanhar o progresso de obras em andamento e compartilhar recomendações em uma interface inspirada em bibliotecas mágicas e clássicas.

---

## ✨ Funcionalidades Principais

### 📊 Dashboard de Controle
Uma visão centralizada onde o usuário pode visualizar imediatamente:
- **Estatísticas de Leitura:** Total de obras, pergaminhos descobertos e recomendações feitas.
- **Lendo Agora:** Acesso rápido às obras que estão sendo consumidas no momento.
- **Novos Pergaminhos:** Sugestões de novas histórias integradas ao catálogo.

### 📚 Biblioteca Pessoal
Gerenciamento completo do seu acervo literário:
- Adição de obras (Livros, Mangás, Novels, etc).
- Controle de status (Lendo, Lido, Dropado).
- Sistema de avaliação por estrelas.
- Notas pessoais e resumos detalhados para cada obra.

### 📜 Pergaminhos (Catálogo)
Um espaço dedicado à descoberta de novas obras independentes e clássicas:
- Classificação de impacto (Classe S, A, B).
- Sinopses detalhadas.
- Críticas e recomendações da comunidade.
- Integração direta: adicione qualquer pergaminho à sua biblioteca com um clique.

### 💬 Recomendações
Sistema de compartilhamento de opiniões:
- Publique recomendações detalhadas sobre suas obras favoritas.
- Edite ou exclua suas postagens conforme sua opinião evolui.

---

## 🎨 Identidade Visual

O projeto utiliza uma estética **Premium Dark Fantasy**, focada em:
- **Paleta de Cores:** Marrom profundo (`#1a0c05`), Dourado envelhecido (`#c5a059`) e tons de pergaminho.
- **Interface Limpa:** Foco total no conteúdo real, eliminando distrações e elementos decorativos excessivos.
- **Efeito Glassmorphism:** Uso de desfoque e transparências elegantes para criar profundidade.

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Next.js 15+](https://nextjs.org/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Componentes:** Baseados em [Radix UI](https://www.radix-ui.com/) para acessibilidade.
- **Persistência:** LocalStorage (para demonstração de protótipo).

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Node.js (versão 18 ou superior)
- pnpm, npm ou yarn

### Instalação
1. Clone o repositório:
   ```bash
   git clone https://github.com/Marcio-ferreira-zh/Beyond-The-Pages.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:3000` no seu navegador.
